# Doctor Assist Prototype (Vercel)

วิธีอัปโหลด
1. ไปที่ vercel.com → Add New → Project
2. เลือก Deploy โดยลากโฟลเดอร์นี้ (หรือ push ขึ้น GitHub แล้ว Import)
3. Framework Preset: Other · ไม่ต้องตั้ง Build Command · Output Directory: ว่าง (root)

หรือใช้ CLI: `npx vercel --prod` ในโฟลเดอร์นี้

หน้า: / (เลือกบทบาท), /patient, /nurse, /doctor, /pharmacist, /admin, /osm
